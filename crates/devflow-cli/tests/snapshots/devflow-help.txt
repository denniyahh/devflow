An opinionated, GSD-native take on AI-driven development automation

Usage: devflow <COMMAND>

Commands:
  start    Begin the workflow for a phase: Plan → Code → Validate
  resume   Resume a phase from its saved stage after a rate limit or infrastructure pause
  gate     Inspect and answer human gates (the pause points where the workflow waits for approval)
  logs     Print or follow an agent's captured output for a phase
  history  Show a phase's chronological events and retained attempt evidence
  cleanup  Remove what is safe to remove: a finished run, a dead start's reservation, or a worktree with no run state, once its branch is merged into the base, its worktree is clean and no run is live. Says why it keeps the rest, and names `devflow discard` (or `devflow resume` for an incomplete run)
  discard  Remove a phase's worktree, its uncommitted changes, its run state, its feature branch, and the gate files and hold temps a killed run left, after listing them. Refuses a live run or a gate something still waits on; refuses an unmerged branch unless `--delete-unmerged-branch` names it
  status   Show current workflow state
  doctor   Audit the environment and report what's installed, missing, or broken
  stop     Stop the phase's DevFlow user service and report how the run ended
  help     Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version
