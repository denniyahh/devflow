## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator CLI -> persisted phase state | `--agent` is operator-supplied and mutates a durable run record |
| persisted state -> detached monitor process | the monitor reads state after this command exits; ordering is the only guarantee |
| DevFlow -> spawned agent process | the relaunch executes a different agent binary against the run's worktree |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-44-01 | Tampering | `Command::Resume { agent }` parsing | low | mitigate | Reuse `AgentKind`'s existing clap value parser (identical to `Start`'s and `Monitor`'s `--agent`); no new parsing surface, unknown values rejected by clap before `resume()` runs |
| T-44-02 | Repudiation | handoff state mutation | medium | mitigate | Mandatory `agent_handoff` event in `.devflow/events.jsonl` with `from_agent`/`to_agent`/`stage`/`reason`, emitted before the relaunch spawns (D-07); asserted by Task 1's tracer test |
| T-44-03 | Elevation of Privilege | relaunch under a different driver at a stage it cannot run headlessly | medium | mitigate | Pre-mutation `preflight_interactivity_check` against a candidate state (D-08); refusal writes nothing; Task 2 Test 1 asserts the on-disk state is unchanged |
