- **Before `/gsd-verify-work`:** Evidence README complete, counts internally consistent, PII scrub verified (zero-match `rg`), `cargo test --workspace` green

## Manual-Only Verifications

Not all phase behaviors are automatable, by design (the honesty criterion):

- **Criterion 2's honesty (negative results recorded as-is):** manual read of the evidence README.
  A `cargo test` cannot verify that the operator did not "assume the answer resolves toward
  the gate works" — the plan pins the posture; the record must show it.
- **Criterion 4's scope statement:** manual read — the record must state sample size, CLI
  version, workload shape, and what the evidence can/cannot support.
- **Criterion 5's Validate-failure count observation:** manual read of the state file at run end.

All other verification (counts, positive controls, PII scrub, build) is automated.
