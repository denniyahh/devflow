<objective>
Delete the branch that makes DevFlow's Define stage ask an interactive question
nobody can answer.

Purpose: `Stage::Define.gsd_command()` returns the discuss-phase command
unconditionally in `idempotent_stage_prompt`'s "artifact does not exist" arm.
Under `claude -p` with no human present, that command hangs or errors on its
first question — the exact failure class this phase exists to close, reached
before any of 28a's machinery would ever engage. D-14 settles the shape: the fix
is deletion. Proceed without a CONTEXT.md, exactly as any early phase with no
context file already does; the operator decides whether to run an interview
entirely before invoking `devflow start`, and DevFlow has no runtime
accommodation to make for that choice.

Output: a Define stage prompt that never invokes an interactive command, with
the Plan stage's identical-looking branch provably untouched.
</objective>
