## Shared recipe: the hostile-`GIT_DIR` harness

```
HOSTILE=$(mktemp -d) && git init -q "$HOSTILE"
GIT_DIR="$HOSTILE/.git" cargo test <scope>
```

A `test result:` line must actually print. A timeout, or a `0 passed` line
(meaning the filter matched nothing), is a FAILURE, not a pass. Never use a bare
`cargo test --workspace` under a hostile `GIT_DIR` — it does not terminate
(`27-RESEARCH.md` Pitfall 2).

   "harmonize" them — they diverge deliberately, documented at lines 400-412.

still be needed but `Command` remains in use by the constructor itself — do not
remove the `use std::process::{Command, Stdio};` import. If clippy reports any
import as unused after the edits, delete that specific import rather than
silencing the lint.

Surgical scope: touch only the constructor call and the `.current_dir` call at
each of the seven sites, plus whatever import cleanup the compiler demands. Do not
reformat adjacent code, do not rename anything, do not restructure the wrappers.
