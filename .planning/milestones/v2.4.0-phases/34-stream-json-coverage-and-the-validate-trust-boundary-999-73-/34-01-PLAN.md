<objective>
Close 999.74's real defect (ROADMAP criteria 4 and 5): `reconcile_layer0_verdict` grafts Layer 1's
`verdict` onto an affirmative Layer-0 probe success while reading only **Layer 0's** status, so a
marker of `{"status":"failed","verdict":"pass"}` launders a self-reported failure into
`(Success, Some(Pass), Some(0))` — which `decide_action` advances and `classify_validate_outcome`
reads as `Passed`, i.e. Ship, in `Mode::Auto`, on a run whose agent reported failure.

Purpose: this is the live route by which an agent's self-report converts a Validate that would
otherwise have gated into a transition to Ship. It is the phase's riskiest architectural claim and
the precondition for plan 34-04 (999.76) — moving Layer 0 discovery to the execution root makes
`decided_by_layer == Some(0)` common rather than rare, which is exactly this graft's precondition,
so 999.76 must not land without this fix (D-15, D-13).

Output: a status-gated graft, the extended cascade fixture reproducing then closing the exploit,
NC-5 and NC-6 as named negative controls, and the corrected in-source record of what the inversion's
real route is.
</objective>
