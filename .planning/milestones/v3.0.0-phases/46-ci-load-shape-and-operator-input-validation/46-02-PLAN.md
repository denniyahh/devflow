<objective>
Stop `ensure_base_is_a_local_branch` from accepting revision expressions, and make the refusal say
something true about WHY.

Purpose: today the function uses `git rev-parse --verify` — a REVISION PARSER — as a ref existence
check. Three spellings measured against a faithful fixture replica pass it and should not:
`workspace/example~1`, `develop@{0}` and `develop^{}`. Worse, when the refusal does fire the single
message advises creating a branch literally named `develop@{0}`, which is nonsense. `show-ref
--verify` is a ref LOOKUP and refuses all three; `check-ref-format` then tells the two refusal
reasons apart.

Output: a two-call implementation of one existing function, and a single extended unit test whose
new arms are proved to fail before the change.

**Phase tracer note:** this phase's `type="tracer"` slice is Plan 01's Task 1 — the CPU-pin
definition site wired end-to-end from the local gate through CI to an in-tree guard, which is the
only architectural bet in the phase. Plans 02 and 03 are independent surfaces with proven in-file
analogs, and both lead RED-first under TDD mode. Stated so the shape is a decision, not an oversight.
</objective>
