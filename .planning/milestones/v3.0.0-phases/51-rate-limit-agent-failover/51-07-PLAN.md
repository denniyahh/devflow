<objective>
D-09, Code half: a fallback (and any other same-stage relaunch) continues the interrupted Code operation — an audit-fix,
gaps-only or full-execute pass — instead of the stage's default execute-phase prompt, by persisting the fix TYPE and
re-rendering it with the current agent's driver in the function that actually builds the agent's prompt.

Purpose: today `launch_stage_inner` rebuilds `StageIntent::Code { fix: None }` on every no-override launch, so a
relaunch mid-audit-fix runs a different workflow. Persisting a rendered string would hand a Claude slash command to
Codex. Changing only `launch_stage`'s render would leave the delivered prompt unchanged with green tests (review B-1),
so the tests assert on what a spawned stub receives.
Output: one state field, serde on `FixType`, the write/clear points, the shared renderer, five tests.
</objective>
