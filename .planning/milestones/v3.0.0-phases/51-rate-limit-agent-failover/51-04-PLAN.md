<objective>
Give the operator the switch (D-01's CLI half): `--fallback-agent <AGENT>` on `devflow start` and on `devflow resume` of
a run that is not live, validated best-effort at launch (D-02, D-03) and persisted in the state file 51-01 added. Every
refusal happens before any write, including the notify command `resume` would otherwise commit first (review B-3).

Purpose: 51-01's failover only fires for a state that already carries a fallback; this makes it configurable from the
command line. The `devflow.toml` key (R-3) is plan 51-14, which builds on this plan's `start` parameter.
Output: the flag on two verbs, one shared validator, `start` persistence, `resume` re-arm, eleven tests.
</objective>
