### IN-03: Test discovery depends on the current directory

**File:** `tests/test_budget_deadline.py:4-5` (same applies to the pre-existing `tests/test_budget.py:3`)
**Issue:** `import probe.budget` only resolves when the repo root is the current directory or on `sys.path`, because `unittest discover -s tests` puts `tests/`, not the root, on the path. I confirmed that running discovery from `/tmp` against this tests directory errors with `No module named 'probe'`, and so does `python3 -I -m unittest ...`. The plan's documented command works from the root, so this is robustness only.
**Fix:** If CI may run from another directory, use `python3 -m unittest discover -s tests -t .` from the root, or set `PYTHONPATH`. Otherwise no change is needed.
