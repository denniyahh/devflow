## Selftest and check conventions (every Phase 49 tool)

Case line `  ok   <name>` or `  FAIL <name> — <why>`; last line `SELFTEST passed=<P> failed=<F>` (or

greps them with `rg -F`. The selftest is hermetic: `mapfile -t v < <(git rev-parse --local-env-vars); unset "${v[@]}"`,
`export GIT_CONFIG_GLOBAL=/dev/null GIT_CONFIG_NOSYSTEM=1`, one `mktemp -d` with `trap … EXIT`, and it runs the script
as a child (`bash "${BASH_SOURCE[0]}" …`). Every control first proves its own precondition (the harness
`scripts/test-phase-worktree-guard.sh:125-131`). Refusals are asserted on their text, never only on the exit code.
Count with `rg --count-matches … || true` then `${c:-0}`; read JSON with `jq -r '(.x // "ABSENT") | tostring'`.
