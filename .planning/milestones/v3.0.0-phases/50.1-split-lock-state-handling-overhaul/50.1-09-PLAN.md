<objective>
Retire the one state writer that runs with no lock on every read (D-11): `migrate_legacy_state` renames
`state.json` to `state-NN.json` inside `load_state` and `list_states`. Under Phase 50 D-20 (no migration) it is
deleted, not routed through the lock.

Purpose: after 50.1-04 every intended state write goes through `update_state`; this removes the unintended one so
50.1-11's "no state write outside `update_state`" scan can hold. Deleting proved wider than the CONTEXT scout saw
(a doc-check path list, a `pub` report field the CLI prints, and an integration test that used the migration's log
line), so those are in this plan's files; CONTEXT D-11 allowed keeping it under the lock instead, but deletion stays
bounded and is chosen.
Output: the deletion and its test, the recover/CLI/doc-check/integration-test follow-ups.
</objective>
