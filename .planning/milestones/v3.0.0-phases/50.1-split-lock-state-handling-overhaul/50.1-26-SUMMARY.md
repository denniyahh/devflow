**2. [Rule 1 - Bug] The runbook's seam check read a missing events file as zero**

- **Found during:** Task 2, the negative control on the first draft (never committed)
- **Issue:** `jq -s` over a missing file prints `0` for each event before it exits non-zero, so a missing file read as a clean `supervisor_superseded=0`.
- **Fix:** the block prints `events=ABSENT <path>` when the file is missing or empty. An unparsable file already prints an empty value. The runbook says all of these mean the read failed.
- **Files modified:** `50.1-RUNBOOK.md`
- **Verification:** four inputs: real, planted bad, absent, malformed
- **Committed in:** `f5d69da`
