### Smaller differences from the plan text

- A live lock beats a STALE pending socket: the plan shuts down any non-GONE socket, and I wait rather than run the backstop. A pending socket that fails its probe refuses.
- `PENDING_PUBLISH_WAIT` is a literal 15 s, because `monitor::PUBLISH_WAIT` is private to core and `monitor.rs` is outside this plan. Nothing ties the two together if core's value changes.

- `PhaseFacts` gains a fifth field beyond the plan's list, `write_lock_error`, so a read failure can be reported.
