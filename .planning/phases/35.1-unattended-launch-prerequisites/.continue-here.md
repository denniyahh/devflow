## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---|---|---|---|
| Comparing a downstream consequence instead of the thing under test | The drill's negative-control check originally compared `auto_approved=X surfaced=Y reached_validate=Z`. `reached_validate` differed between arms for reasons unrelated to auto-approval, so the arms registered as "different" even on a run where BOTH arms had auto-approved (masking a real failure). | blocking | Fixed in commit `51178b4` — the compared string is now `auto_approved=X surfaced=Y` only. If you find yourself widening this string again, ask whether the new field is actually part of the checkpoint decision or just correlated with it. |
| A fixture's persistent config can satisfy the same boolean the mechanism-under-test sets | GSD's `checkpoint_handling` reads "chain flag OR user preference — same boolean" (`gsd-core/workflows/execute-phase.md`). The fixture originally set `workflow.auto_mode: true`, so the *preference* alone caused auto-approval in both arms regardless of DevFlow's ephemeral chain flag — the actual thing being measured. | blocking | Fixed in commit `51178b4` — fixture now sets `auto_mode: false`. Verified by scaffolding a fixture and reading the emitted `config.json`. If a future fixture edit reintroduces `auto_mode: true`, the drill will silently measure nothing again, the same way it did the first time. |
| Treating an idle-timeout gate message's commit count as "this attempt's" work | The phase 35.1 live dogfood run's gate context says "The agent made 35 commit(s) before going quiet" — that is commits ahead of `develop` for the WHOLE phase, cumulative, not commits made by the failing attempt. The failing attempt itself made zero. This is a known DevFlow defect (the never-silent commit check isn't scoped to the stage attempt) — do not let it talk you into approving a gate as if real work just happened. | advisory | Always check `git log --since=<stage-launch-timestamp>` on the actual worktree before trusting a gate's commit count. |
