## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Rust built-in `#[test]` / `cargo test`; workspace crates `devflow-core` (lib target) and `devflow` (bin-only) |
| **Config file** | none — no `.cargo/config.toml` test-runner override |
| **Quick run command** | `cargo test -p devflow-core --lib <module>::` (module-scoped) |
| **Full suite command** | `cargo test -p devflow-core --lib && cargo test -p devflow --bin devflow` |
| **Estimated runtime** | ~60–180 seconds (full workspace suite) |

> **Repo trap (CLAUDE.md, already paid for):** `cargo test -p devflow --lib` verifies nothing —
> `devflow` is binary-only and cargo exits non-zero with `error: no library targets found in package
> 'devflow'` before running a test. Use `-p devflow --bin devflow` (or `--test <name>` for the
> integration files). `-p devflow-core --lib` *is* valid.
>
> **Repo trap:** `cargo test --exact <name>` exits 0 when the name matches nothing. Assert on a real
> `1 passed` with a non-zero `filtered out` count.

---

## Sampling Rate

- **After every task commit:** Run `cargo test -p devflow-core --lib <touched module>::`
- **After every plan wave:** Run `cargo test -p devflow-core --lib && cargo test -p devflow --bin devflow`
- **Before `/gsd-verify-work`:** Full suite must be green **and** the criterion-5 live drill run with
  its evidence captured — criterion 5 explicitly forbids treating unit tests as sufficient proof.
- **Max feedback latency:** 180 seconds
