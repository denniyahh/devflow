<objective>
D-09, Code half: a fallback (and any other same-stage relaunch) continues the interrupted Code operation — an audit-fix,
gaps-only or full-execute pass — instead of the stage's default execute-phase prompt, by persisting the fix TYPE and
re-rendering it with the current agent's driver.

Purpose: today `launch_stage` rebuilds `StageIntent::Code { fix: None }` on every no-override launch, so a relaunch
mid-audit-fix runs a different workflow. Persisting a rendered string would hand a Claude slash command to Codex.
Output: one state field, serde on `FixType`, the write/clear points, the replay, four tests.
</objective>
