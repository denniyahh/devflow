<objective>
Build the three tools the operator runs from their own terminal:
- `launch-attempt.sh <N>` starts one attempt. It checks the preconditions, rebuilds and pins the binary, records its
  identity, runs the negative arm, starts the watcher units and launches the positive arm in its own systemd unit.
- `gate.sh` answers a gate with that attempt's binary.
- `archive-attempt.sh` preserves an attempt before a retry is allowed to destroy it.

Purpose: the live run must be launched and owned outside any agent worktree or subagent turn (CONTEXT Claude's
Discretion; memory: long probes live outside agent worktrees). So the operator runs these, and the executors only
verify. Each check sits where a wrong launch would otherwise cost an attempt: D-11 caps attempts at 3. Output: three
scripts, tested here without launching the live run.
</objective>
