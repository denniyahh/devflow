## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-49-09-01 | Information disclosure | a public throwaway repository | high | mitigate | `start` refuses unless `gh repo view` says `PRIVATE` (selftest control) |
| T-49-09-02 | Tampering | run targeting this repository | high | mitigate | `start` refuses a `nameWithOwner` equal to this repository's origin (selftest control); the payload lives under `$P49` outside every checkout |
| T-49-09-03 | Spoofing | nested agent inheriting the Claude session environment | medium | mitigate | `systemd-run --user` clean environment with only PATH, HOME and the hook command |

| T-49-09-05 | Elevation of privilege | automated gate approval | high | mitigate | No gate verb and no `yes_ship` write in the tool (gate-checked); Ship pre-authorization comes only from the typed `--yes-ship` flag (D-23) |
| T-49-09-06 | Repudiation | unpinned or rebuilt binary mid-attempt | medium | mitigate | Pinned file named by its sha256, mode 0555, never overwritten; sha recorded in `attempt.json` and checked by `--pair` |
