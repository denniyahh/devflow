<objective>
Build the tool that undoes the post-Ship release side effects once they have been recorded (D-08, ND-2). The
post-Ship hooks run Merge, then VersionBump, then ChangelogAppend, then BranchCleanup. VersionBump commits
`chore: bump version to 3.0.0` and creates an unsigned lightweight tag `v3.0.0`. ChangelogAppend commits
`docs: add changelog entry for 3.0.0`. The tag carries this milestone's real release name, so it must not survive.

Purpose: reset-based undo (RESEARCH Pattern 9, recommended over revert because nothing is pushed and revert would
leave two noise commits), made safe by guards that refuse every layout that is not exactly the expected one.
Output: `tools/undo-ship-hooks.sh`.
</objective>
