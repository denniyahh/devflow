<objective>
Build the two tools that capture evidence at each gate without an agent present. `snapshot.sh` copies what exists at
one moment. `gate-watch.sh` runs in its own systemd unit for the whole run. It notifies the operator when a phase-49.1
gate opens, snapshots it, appends to the ledger, and keeps every generation of the prompt file. The prompt file is
overwritten at each launch and never archived (RESEARCH Pitfall 6; `history/` keeps stdout, exit and REVIEW only).

Purpose: evidence at gates that can wait days must not depend on an executor being awake (D-13, D-16; CONTEXT
"How the operator learns a gate is waiting"). Output: `tools/snapshot.sh` and `tools/gate-watch.sh`.
</objective>
