<objective>
Build one credential scanner that both public exposure points use, so a public PR body or a committed evidence excerpt
is refused if it carries any credential shape on the list or any credential value the environment actually holds.

Purpose: the adversarial review (2026-09-25, codex #6 and agy #2) found 49-15 scanning only three prefixes and 49-12
adding `ANTHROPIC_API_KEY=` but not `ANTHROPIC_TOKEN`, although RESEARCH's security register names both. Two hand-typed
lists drift; one tool with one list cannot. The sanitiser half makes 49-15's redaction reproducible instead of manual
(codex #12). Output: `tools/secret-guard.sh`.
</objective>
