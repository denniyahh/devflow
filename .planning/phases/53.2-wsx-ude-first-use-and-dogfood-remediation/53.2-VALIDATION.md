## Sampling Rate

- **After every task commit:** Run the task's named test(s) via the quick run command, plus the revert check once (D-17)
- **After every plan wave:** Run `cargo test -p devflow-core --lib && cargo test -p devflow --bin devflow`
- **Before `/gsd-verify-work`:** `scripts/check.sh all`, `scripts/check-in-container.sh`, `scripts/check.sh service` (host), semver gate
- **Max feedback latency:** 60 seconds for a single named test
