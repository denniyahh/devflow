## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Rust built-in tests run by cargo-nextest; `insta` for prompt snapshots |
| **Config file** | workspace `Cargo.toml`; `scripts/check.sh` |
| **Quick run command** | `cargo nextest run -p <pkg> (--lib \| --bin devflow \| --test <t>) --no-tests=fail -E 'test(=<path>)'` |
| **Full suite command** | `scripts/check.sh all` then `scripts/check-in-container.sh`; host-only `scripts/check.sh service` |
| **Estimated runtime** | quick ~30 seconds; full suite several minutes (container push 2–9 min cold) |

---

## Sampling Rate

- **After every task commit:** Run the task's named test(s) via the quick run command, plus the revert check once (D-17)
- **After every plan wave:** Run `cargo test -p devflow-core --lib && cargo test -p devflow --bin devflow`
- **Before `/gsd-verify-work`:** `scripts/check.sh all`, `scripts/check-in-container.sh`, `scripts/check.sh service` (host), semver gate
- **Max feedback latency:** 60 seconds for a single named test
