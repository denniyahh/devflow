## Accomplishments

- `gsd_derived_paths_warning` runs `git check-ignore -q` (through `git_command`, no `--no-index`) for `.planning/state.json`, `.planning/milestone.lock` and `.gsd/dispatch-isolation-sentinel.json`. Exit 1 lists the line, any other status or spawn error is listed as `could not check …` with git's error, and it returns `None` outside a git work tree. `start` prints it immediately before `if dry_run`, after the external-verify warning and the fallback refusal.
- `start` reads the state back from disk after `start_reserved` returns. On a NotLive timeout, `not_live_after_timed_out_launch` reloads it and clears the run only on JSON equality. Otherwise it keeps the run and says: `start: phase N was not confirmed launched (…), and its run state changed after start wrote it, so it was kept: run `devflow status` to inspect it, and `devflow discard --phase N` to remove it`.
- `re_mark_stopped_after_failed_launch` keeps `stop_reason` when the state on disk already reads `stopped`.
- #258 comment: https://github.com/denniyahh/devflow/issues/258#issuecomment-7093747155 (test name, reproduced, failing text, fix commit, and the advanced-then-died sibling as an open question).
