## Deviations from Plan

**1. [Plan error, site kept] gsd_reader.rs's 0o755 launcher not converted**
- Found during: Task 2
- Issue: the plan's only 0o755 site in gsd_reader.rs (~1023) is `launcher_whose_writer_a_fork_holds`. Its doc says it uses `File::create` on purpose: the 999.222 reproduction needs this process to hold a write fd on the launcher at the fork. Converting it would make that reproduction vacuous. It is also not an `fs::write` + `set_permissions` pair.
- Fix: left unchanged, like the plan's "leave it and record it" clause for sites that cannot be converted. **53.2-07's allowlist must name `gsd_reader.rs` `launcher_whose_writer_a_fork_holds`**, along with the 0o644 chmod. The must-have line that lists gsd_reader.rs's 0o755 fixture as converted is not met, for this reason.

- Issue: Task 1 used `write_executable(&stub, &script)` as the plan wrote it, but that script is already a `&str`, so `clippy::needless_borrow` fails under `-D warnings`.
