## SUSPECTED

1. **[major] (Speculation) `53.2-06-PLAN.md` Task 2 (`#296`): `/proc/$pid/fdinfo/$num` redirection error noise and `dash` portability in `FAKE_SYSTEMD_RUN_CALLS`**
   - `53.2-06-PLAN.md:102` relies on `[ /proc/$pid/fd/N -ef "$lock" ]` and `while read ... < /proc/$pid/fdinfo/$num` inside `#!/bin/sh` (`crates/devflow-cli/tests/common/mod.rs:287`), which runs under `dash` in the pinned Debian bookworm devcontainer (`.github/workflows/ci.yml:49, 116`). While `dash` supports `-ef`, if the child closes an fd or exits between the `/proc/$pid/fd/*` glob and opening `/proc/$pid/fdinfo/$num`, an unguarded shell redirection writes a `cannot open` error onto `systemd-run`'s stderr, potentially failing stderr assertions in e2e tests.

2. **[minor] (Speculation) `53.2-12-PLAN.md` Task 3 (`#258` resume sibling): runner that advances and crashes still gets `"resume launch failed"`**
   - `53.2-12-PLAN.md:141` skips overwriting `stop_reason` in `re_mark_stopped_after_failed_launch` (`crates/devflow-cli/src/pipeline_launch.rs:2247-2254`) only when `s.stopped` is already `true` on disk. 3. **[minor] (Speculation) `53.2-13-PLAN.md` Task 2 (`#324` custom Rust string lexer): byte/c-string literals and `b'"'` not listed**
   - `53.2-13-PLAN.md:109` specifies handling `"..."`, `r#"..."#`, `'"'`, and `'\"'`, but omits byte/C string prefixes (`b"..."`, `br#"..."#`, `c"..."`) and byte-char `b'"'`.
