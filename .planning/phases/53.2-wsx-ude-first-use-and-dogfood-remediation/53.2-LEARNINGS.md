### --until halt records its target; resume --reviews reruns the halted Plan
State::until_halt_target holds the transition target; resume_advance reads it, enter_stage clears it on every entry. resume --reviews is refused before any write unless the --until plan cap halted Plan and NN-REVIEWS.md exists in the run's checkout; it keeps the cap.

**Rationale:** One place computes the advance target, and a stale target cannot outlive its stage. start --reviews checks REVIEWS.md on the resolved base, so a primary-checkout copy is refused.
**Source:** 53.2-14-SUMMARY.md, 53.2-15-SUMMARY.md, 53.2-17-SUMMARY.md

The fake uses a per-launch NOTIFY_SOCKET listener and kills it on early-exit paths, replacing the held-runner-lock read from /proc fdinfo.

**Rationale:** Supersedes D-14's readiness clause; the lock-based negatives passed only because no child sent READY=1.

## Patterns

### Plan prompt branch order
PLAN.md exists -> success; else CONTEXT.md missing -> discuss, re-check CONTEXT.md, re-probe PLAN.md, plan; else plan.

**When to use:** Any prompt that chains stages: re-probe after the intermediate step so an auto-advancing project does not do the work twice.
**Source:** 53.2-01-SUMMARY.md

---

### Route test stubs through write_executable
Every 0o755 text-stub site in core and CLI tests converts to write_executable; sites that must keep a raw writer are listed with reasons in a kept list.

**When to use:** Test fakes that are executed right after writing (ETXTBSY risk).
**Source:** 53.2-03-SUMMARY.md, 53.2-04-SUMMARY.md, 53.2-07-SUMMARY.md

---

### Guard takes its kept list as a parameter
permission_setters(sources, kept) lets planted controls run against an empty or planted kept list; the guard's own needle is built with concat! so it does not match itself.

**When to use:** Source-scan guards that need negative controls.
**Source:** 53.2-07-SUMMARY.md

---

### Hermetic child test
run_hermetic_test_in_child with DEVFLOW_BASE_BRANCH empty and a git-only PATH, so host values cannot pick the base; a lock holder is the test binary re-run as an #[ignore] child, not flock(1).

**When to use:** Tests that depend on environment or on tools the pinned image may lack.
**Source:** 53.2-05-SUMMARY.md, 53.2-06-SUMMARY.md

---

### Reproduce on base before claiming a fix
Run the same loop at base, after and changed, count passes two ways (nextest summary and exit codes), and record the result on the issue; reverse control restores GREEN bytes and reruns.

**When to use:** Flaky-failure issues (#265, #310): a null base loop means the issue stays open.
**Source:** 53.2-02-SUMMARY.md, 53.2-09-SUMMARY.md, 53.2-12-SUMMARY.md

---

### Semver-checks with a variant at the end of an enum
Add new variants last and match the list pattern ending at ` in` so a longer variant name cannot match.

**When to use:** Additive changes to published enums.
**Source:** 53.2-10-SUMMARY.md

---

### Kill a fake's helper on every exit path
The fake systemd-run kills its listener when it never marks itself started or cd fails, and .launched is read only once its newline is written.

**When to use:** Test fakes that spawn background helpers (T-53.2-33).
**Source:** 53.2-18-SUMMARY.md
