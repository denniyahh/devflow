> Per-phase security contract: threat register, accepted risks, and audit trail.

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| operator → question gate → agent | discuss answers come only from `devflow gate answer`, then become CONTEXT.md | operator answers (trusted) |
| agent → question gate file → status output | option ids are agent-supplied text printed to the operator's terminal | untrusted agent text |
| test process → sibling forks | inherited write descriptors on exec'd stubs and fakes (test-only) | file descriptors |
| test fake → binary under test | fakes stand in for systemd start/readiness (test-only) | readiness signal |
| source tree → guard test | scans read repository files only (test-only) | source text |
| CI environment → test budgets | `CI` and the override come from the runner's environment (test-only) | env values |
| repository → required status check | devcontainer job name is a required check on `develop` | CI config |
| process → libc time zone database | `localtime_r` reads TZ and /etc/localtime | TZ data |
| published crate API → downstream users | devflow-core is on crates.io | public API |
| test teardown → host processes | teardown must not kill an observing DevFlow run | process handles |
| devflow → git | fixed argv, project root as cwd | constant paths |
| systemd-run timeout → state deletion | destructive clear decided on incomplete evidence | run state |
| concurrent foreground verbs → one phase's state | stop/resume/discard/cleanup serialise on the phase holder | run state |
| persisted state / operator flag → resume → agent prompt | `.devflow/state-NN.json` and `--reviews` decide which stage and GSD mode runs | run state |
| scratch runs → operator's live run | must not share `.devflow/`, install root or units | install root, units |
| runner unit → run state file | failed-launch path must not overwrite a runner's state with a false halt | run state |
