with each gate side effect, not a check before it (R-09, and T-50.1-66 is no longer accepted); the promotion deadline
must run beside the agent, not after it, or an orphan with a never-ending agent lives on (R-12, D-15's intent); and the
rule for when a group may be signalled is fixed before the seam is built (R-13).
