<objective>
Generalise Phase 50's `names_this_launch` check into the ownership fence (D-03), add the bounded promotion wait and the
orphan's self-end (D-15), and remove the long lock from `advance` (D-08), whose implicit ordering the promotion wait now
replaces.

Purpose: today `advance_with` binds only by stage and never reads `state.supervisor.launch_id`; a supervisor the state no
longer names can still write state, consume an answer, clean gates and spawn a stage. And with no long lock, a fast
agent's advance can run before its launcher promotes it (Pitfall 5), so "only pending" must mean "wait", and an expired
wait must mean "I am an orphan — end, write nothing".
Output: the engaged fence, `await_promotion`, superseded/orphan handling, `Supervisor::end_agent_group`,
`clear_state_if_owned`, and the V-23/V-24/V-27 tests.
</objective>
