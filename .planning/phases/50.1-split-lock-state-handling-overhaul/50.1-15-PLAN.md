<objective>
Delete the unkeyed gate API and the transition bridge from `devflow-core` now that nothing in the CLI uses them
(50.1-14), and make the gate id required.

Purpose: D-05's binding should not rest on every caller remembering to use the keyed functions; with the old ones gone,
a regression is a compile error. Remaining core callers (`recover`) and test fixtures move to the keyed API.
Output: the deletions, `GateFile.gate_id` required, `recover` on `close_with_partial_result`, migrated tests.
</objective>
