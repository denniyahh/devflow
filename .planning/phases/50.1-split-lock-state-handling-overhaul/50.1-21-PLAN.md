<objective>
Fix 999.166 item 2 and finish D-08 in `devflow-core`: `recover --clean` decides liveness from the supervisor socket, the
pending reservation and the gate registration instead of the per-phase lock, and the per-phase pid-lock API is deleted.

Purpose: OPERATIONS says `recover --clean` probes the supervisor socket; without `--phase` it does not, and today it can
delete a live supervisor's state between its agent's exit and its advance (999.166 item 2). With no long lock left
(50.1-16/-19/-20), the lock it relied on no longer means anything, so the probe must be explicit.
Output: `recover::phase_may_be_live` and its callers, the `.live` sweep, the lock API deletion, rewritten tests.
</objective>
