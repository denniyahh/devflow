<objective>
Build D-01's liveness primitive in `devflow-core`: a per-launch lock file whose `flock` a launcher takes before it
saves a pending record and a spawned supervisor inherits and holds for life, so a pending supervisor is probeable
before its socket exists and an abandoned reservation is told apart from a live one — without reading a pid.

Purpose: a pending record probed by socket alone reads GONE during exactly the window it exists for (CONTEXT D-01,
all three review lanes). The guard (50.1-16), the S(N)→N+1 handoff (50.1-17), `stop`/`status` (50.1-18) and the gate
waiter registration (50.1-08) all probe through this module. The two probe-verified traps (Pitfalls 1 and 2) are
pinned by tests here, before any caller exists. The sidecar directory fsync (D-09) rides along because this plan owns
`supervisor.rs` in its wave.
Output: `crates/devflow-core/src/liveness.rs` with tests; `supervisor.rs` changes.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| launcher → supervisor (exec) | a descriptor deliberately inherited across exec |
| supervisor → agent (exec) | descriptors the agent must not inherit |
| on-disk launch id → path | a launch id read from state or a file name used to build a path |
