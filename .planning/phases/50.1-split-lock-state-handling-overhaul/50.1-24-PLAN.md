Fix 999.166 items 6 and 1 (D-16, D-13), failing-first: `stop` says what actually happened, and the exit file records the
stop outcome after a safe-point stop.

Purpose: item 6 — a stop honoured at an advance safe point prints "agent group ended" although nothing was signalled, and
leaves the exit file with the agent's own code (`0` after a completed run) beside the 143 reply; D-16 chose to fix the
exit file (not accept it). Item 1 — `stop` prints "did not answer the shutdown … nothing was signalled or recorded" for a
stop the supervisor accepted and will still honour; with the advance lock gone (50.1-19) the window shrinks but hooks,
preflight, the canary and Ship finalization remain.
Output: the protocol and outcome fields, the corrected lines, the exit-file write, and the tests (E3 rewritten).
