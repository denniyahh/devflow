Finish D-06 and D-05's reporting: `resume` closes the gate it abandons and tells the operator what it set aside, and

supervisor dies before it records the decision is removed with its claim when `resume` closes the gate. 50.1-06 returns
it in `CloseReport.claimed` and logs it; this plan makes `resume` say so, and proves it with the kill-point fixture D-12
requires for each new crash window, using 50.1-19's `after_claim` hold point.
</objective>
