# Phase 52.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Rust libtest + cargo-nextest |
| **Config file** | none beyond Cargo.toml |
| **Quick run command** | `cargo nextest run -p <pkg> <--lib\|--bin devflow\|--test FILE> --no-tests=fail -E 'test(=<full::path>)'` (one test per command) |
| **Full suite command** | `scripts/check.sh all`, then `scripts/check-in-container.sh` |
| **Estimated runtime** | not measured this session (container run historically 2-9 min) |

---

## Sampling Rate

- **After every task commit:** the task's named nextest gates
- **After every plan wave:** `cargo test -p devflow-core --lib && cargo test -p devflow --bin devflow` (in-process runner, where the cross-test fork races live) plus touched integration test files
- **Before `/gsd-verify-work`:** `scripts/check.sh all` green and `scripts/check-in-container.sh` green on the same code (its exit status written to `52.1-CONTAINER-RECORD.txt` by `52.1-repeat-harness.sh container` and read back by `52.1-repeat-harness.sh container-check`), then the D-15 proof run on the installed phase-head binary
- **Max feedback latency:** per-task named gates; full suite not measured
