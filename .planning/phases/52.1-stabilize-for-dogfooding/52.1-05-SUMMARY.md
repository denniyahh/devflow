# Phase 52.1 Plan 05: v4 Proof Fixture in the Default Scaffold Summary

**`scripts/scratch-dogfood-repo.sh`'s default mode now writes the v4 proof-run fixture: a GSD-serialized config that
GSD 1.21.0's own chain-flag write leaves clean, the gate keys that keep ui and drift wave gates off, and a pre-written
validation map.**

## Read this first

- **Assumption A3 is untested until 52.1-14.** The pre-written `01-VALIDATION.md` is there so `/gsd-validate-phase`
  audits an existing map instead of reconstructing one. Nothing in this plan ran `/gsd-validate-phase`, DevFlow or any
  agent. Whether the fixture is enough for a v4 Validate to pass is decided only by the live run.
- **This plan stopped once, at its precondition.** The plan required GSD 1.20.1; the installed GSD is 1.21.0. The
  orchestrator resolved the stop by amending the plan (commit `24c90a6`) under the operator's standing delegation for
  tooling drift. That was the orchestrator's ruling, not a new operator statement. Details under Deviations.
- **Nothing runs `--selftest` automatically.** `scripts/check.sh`, the hooks, CI and the Rust tests do not call it
  (searched: no hit). The tree pin and the new cases protect the fixture only when someone runs the selftest by hand.
  Its hook cases need an installed GSD, so it cannot simply be added to CI.

  mode: the Rust suite does not exercise this script's scaffold.
