**Hermetic git per command** (lines 42-62) — copy this, it nulls global/system config (defeats a user's
`commit.gpgsign=true`, which matters because `cut-pr-branch.sh` runs `git commit -C "$HASH" --no-verify`) and scrubs
repo-local vars. Use the same env on the `bash <script>` command, not only on fixture git calls:
```rust
fn git(repo: &Path, path: &str, args: &[&str]) -> Output {
    let mut cmd = Command::new("git");
    cmd.current_dir(repo).args(args)
        .env("PATH", path)
        .env("HOME", repo)
        .env("GIT_CONFIG_GLOBAL", "/dev/null")
        .env("GIT_CONFIG_NOSYSTEM", "1");
    for var in ["GIT_DIR", "GIT_WORK_TREE", "GIT_INDEX_FILE", "GIT_COMMON_DIR",
                "GIT_CONFIG", "GIT_PREFIX", "GIT_OBJECT_DIRECTORY",
                "GIT_ALTERNATE_OBJECT_DIRECTORIES"] {
        cmd.env_remove(var);
    }
    cmd.output().expect("run git")
}
```
Prefer the shared list over the hand list: `devflow_core::test_support::REPO_LOCAL_GIT_VARS` and
`ALSO_REDIRECTING_GIT_VARS` (re-exported from `crates/devflow-core/src/git.rs` L27/L55; used by
`tests/common/mod.rs` `hermetic_devflow` L80-95). `devflow_core::test_support::git_command(root)` (git.rs L72) is the
other accepted constructor (used by `phase7_cli.rs` L17-31), but it does not null global config — add
`GIT_CONFIG_GLOBAL`/`GIT_CONFIG_NOSYSTEM` on top for the script runs.

**Fixture repo builder** (lines 63-85, `staged_repo`): `init -q -b <branch>`, `user.email`, `user.name`, then files.
For `cut-pr-branch.sh` the fixture also needs a bare `origin` with `develop` pushed, because the script runs
`git fetch "$BASE_REMOTE" "$BASE_BRANCH"` and uses `BASE_REF=origin/develop` (cut-pr-branch.sh L60-62, L114-115) and
refuses a dirty tree (L109-112).

**`describe(&Output)`** (lines 99-106) for every assertion message; **one scenario per `#[test]`** (lines 108-179:
refused / clean / missing-scanner are three tests). Assertion idiom — exit status AND the named text AND the effect:

```rust
pub fn wait_for(mut predicate: impl FnMut() -> bool, timeout: Duration, what: &str) {
    let started = Instant::now();
    while !predicate() {
        assert!(started.elapsed() < timeout, "timed out after {timeout:?} waiting for {what}");
        std::thread::sleep(Duration::from_millis(25));
    }
}
```
