<objective>
Make the push-time divergence check judge the commits being pushed, not whatever the pushing checkout has on disk (999.231). Today the hook checks only when the checkout has a manifest file and reads every input from the checkout, so it fails open for a workspace branch pushed from a develop-based checkout and refuses a clean PR branch pushed from a workspace checkout.

Purpose: the by-hand close-out after the proof run pushes PR branches from a workspace checkout; a false refusal or a fail-open there erodes the close-out path this phase must leave working.
Output: the per-commit script, the per-SHA hook dispatch, its first behavioural tests.
</objective>
