## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| test build → release build | cfg-gated test behaviour must not reach the published binary |
| forked child → multi-threaded parent | the child runs in a copy of a process whose other threads may hold locks |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-52.1-01 | Tampering | gsd_reader `spawn_reader` retry | medium | mitigate | retry compiled only under `cfg(any(test, feature = "test-support"))`; Task 1 proves with `cargo tree` that the normal edge set carries no `test-support` |
| T-52.1-02 | Denial of service | `fork_held_before_exec` child | medium | mitigate | child calls only `read` and `_exit`; `Drop` releases and reaps, so a failing test cannot leave a parked child or a hang |
| T-52.1-SC | Tampering | package installs | low | accept | this plan installs no package |
</threat_model>
