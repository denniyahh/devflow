<objective>
Close WR-01 from 47-REVIEW.md. The worktree-guard test's scratch repository inherits the operator's
global git setup, so its bootstrap commit can abort before any case runs.

**In scope by operator decision 2026-09-11 (A2).** The verifier ruled WR-01 not a Phase 47 must-have,
and it maps to neither DECN-02 nor DECN-03. `requirements` therefore names the review finding rather
than claiming a DECN link that does not exist (see the ledger).

**The review's diagnosis is incomplete. Verified at planning time, with controls:**
- **Host config.** The global config sets `core.hooksPath` (a pre-commit that runs gitleaks),
  `commit.gpgsign true` and `gpg.format ssh`.
- **Signing alone aborts the commit.** In a scratch repository with the ssh-agent removed and hooks
  disabled, the commit still fails: exit 128, "Enter passphrase … failed to write commit object".
- **The hook alone does not.** With signing disabled and the inherited hook active, gitleaks runs,
  finds no leaks, and the commit exits 0.
- **The real script** under the same agent-less condition exits 128 before any case (re-observed
  2026-09-12 on copies of the current script: `host_no_agent_exit=128`).
- **Environment-injected config outranks repository-local config** (review finding 10, probed
  2026-09-12 with git 2.55.0): with a repository-local `core.hooksPath=/local-hooks`,
  `GIT_CONFIG_COUNT=1` plus `GIT_CONFIG_KEY_0`/`GIT_CONFIG_VALUE_0` reads back the injected value, and
  so does `GIT_CONFIG_PARAMETERS`. A `GIT_CONFIG_KEY_0` without `GIT_CONFIG_COUNT` is ignored, so
  unsetting the two carriers is enough.

So disabling hooks alone — the reviewer's suggested fix — would not fix the observed failure, and
repository-local settings alone would not survive injected config. This plan isolates the fixture
from inherited hooks and commit signing through repository-local config, and clears the two
environment carriers at the script's existing hermetic `unset` line. That satisfies the operator's
intent (the bootstrap must not be aborted by inherited global state) and does not contradict it.

Output: a hermetic bootstrap, a permanent case 7 that fails on any host if the repository-local
isolation is removed, and an updated checklist line.
</objective>
