<objective>
Prove, end-to-end against a real remote, that a completed DevFlow Ship performs zero
git mutation — then make that true by deleting the release-acting hook class and
rewiring its production callers, and re-document `workflow_shipped` in the same change
so the event's meaning is never ambiguous.

This is the phase's tracer: one thin slice through the test harness, the CLI binary,
the finalization path, the hook dispatcher, and git — wired end-to-end and carrying a
real runnable verification. Every later plan in this phase expands outward from it.

Purpose: the historical defect merged locally and never pushed, so a push-rejecting
hook could never catch it (review finding H4). Divergence is the only assertion that
can. Building the fixture FIRST and observing it red is what makes the deletion a
proof instead of a hope.

Output: a hermetic divergence-first integration test; a `hooks.rs` that can no longer
express release-acting; a finalization path with nothing left to retry; and a
`workflow_shipped` event whose documentation matches what it now attests.
</objective>
