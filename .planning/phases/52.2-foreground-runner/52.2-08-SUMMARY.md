## Deviations from Plan

**1. [Rule 1 - Bug] Two resume waits in gate_notify_persist_e2e raced resume's return**
- **Found during:** Task 1.
- **Issue:** `resume_with` panicked if `resume` exited between its last state read and its exit poll, and `wait_for_first_stage_launched` failed whenever `resume` returned before its runner emitted `stage_launched`, which D-11 makes the normal order.
- **Fix:** read the state once more after the exit; wait for the event while a successful `resume` has returned, failing only on a non-zero exit or the 20 s bound.
- **Commit:** `6fcca20`.

**2. [Plan wording] The failed-agent arm of auto_chain_flag_e2e reaches its advance**
- The old arm proved the flag clears on `run_monitor`'s early `Err` return. In the runner an agent that cannot be executed exits 127 and its stage is evaluated `agent_unavailable` (seen: `advance_evaluated` with that status, then a stage-failure gate); no spawn error reaches `run_one_stage`. The guard drops when the stage returns, before that advance, so the arm now asserts the evaluated status and the cleared flag (seeded true).

**3. [Plan wording] Exit codes after an abort**
- Old drivers exited 0 after `gate abort`; the runner exits 1 there by design (52.2-02, `runner_exit_code`). The ported tests assert code 1 next to the unchanged event and state assertions.

**Total deviations:** 1 test race fixed, 2 wording notes. **Impact:** no production change; no new deferred item.
