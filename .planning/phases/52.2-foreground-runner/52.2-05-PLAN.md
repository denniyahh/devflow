<objective>
Make the runner stop correctly (D-05, D-04b): one signal handler, a whole-run stop token, a stop recorded as `stopped`, and an exit classification that drains the runner's own pending stop first so a unit-wide SIGTERM never reads as a stage failure. The `devflow stop` verb itself moves to the unit in plan 52.2-06; here the tests signal the runner directly.

Purpose: under `KillMode=control-group` systemd SIGTERMs the agent too, which can end it before the stop is recorded (CONTEXT D-04b).
Output: the single-handler install, drain-and-grace classification, stop recording in the runner, and the carried ordering tests.
Spec-less phase: truths derive from CONTEXT.md decisions.
</objective>
