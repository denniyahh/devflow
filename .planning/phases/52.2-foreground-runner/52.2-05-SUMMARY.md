# Phase 52.2 Plan 05: The runner stops Summary

**A SIGTERM or SIGINT to `devflow __runner` now ends the running agent's group, in any stage, records `stopped` and exits 143. A stop that reaches the agent before the runner reads `stopped`, not a failed stage, and the carried orderings hold on the runner: gate stop, approval stop, hand-back stop, and finish over a late stop.**

## Accomplishments
- The process has one SIGTERM/SIGINT handler. `install_holder_stop_handler` calls `install_signal_pipe`, and the handler stores the caught signal in an atomic before it writes the pipe byte. Its only `sigaction` call is in runtime.rs's `install_once`.
- `StopToken::begin_agent(pgid)` re-arms the run-long token for each stage. `monitor::run_stage` calls it after the pgid check and ends the new group at once when a stop is already pending.
- `spawn_signal_dispatcher` (thread `runner-signals`) is the runner's only reader of the signal pipe. It starts before READY and is dropped when `run_runner` returns. While an agent runs it SIGTERMs, then SIGKILLs, that stage's group. In advance or gate phases it only sets the flag. `SIGNAL_READ_FD` is read in the dispatcher and in `Control::run` (until 52.2-24).
- `run_runner` engages `StopTokenGuard::engage_token`, so its writes are unfenced. Every advance result is read in the order finished, then stop, then Err, then next.
- `wait_owned_agent` reads how the agent ended from `waitid` before the reap. A death by SIGTERM/SIGINT or an exit of 143/130 waits up to 500 ms for the runner's own signal.

- **Fix:** additive `pub fn stop_source(&self) -> Option<StopSource>`. semver-checks passes.

**2. [Rule 1 - Bug] Stop re-read after a failed-advance recovery**
- **Found during:** Task 1
- **Issue:** `recover_failed_advance` can open an infra gate and wait. A stop there returned an Err that would end the runner as an error rather than as stopped.
- **Fix:** `settle_advance` checks finished and then stop again before propagating the recovery's result.
- **Committed in:** 144b327

- On the gaps_found row, the advance hands back the next launch with no safe-point stop. The runner then records `runner_stopped`. The test asserts exactly one stop event (`advance_stopped` or `runner_stopped`) and no further `stage_launched`, rather than the supervisor test's `advance_stopped`.
