# Phase 52.2: Flake Evidence (52.1 D-08) and the Green Commit (D-07b)

Harness: `scripts/repeat-named-test.sh inprocess '<target>' <full::path> <count>`. Every in-process run is the whole
unfiltered `cargo test <target>`, so the named test shares its process with its siblings. A run counts only when cargo
exits 0 and the output has the line `test <full::path> ... ok` exactly once. Full paths were taken from `--list`
output of each target before the runs.

N passes bound nothing about a rate: nobody measured the original rates, and each flake was seen once or twice. The
counts below are N runs on one developer host (Fedora Kinoite, 2026-11-17), at the head after 52.2-17 (`bae9de8`) with
only the uncommitted harness added; no crate source differed from `bae9de8`.
