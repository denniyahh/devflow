  <name>Task 1: End-to-end "one named flake test repeated N times, recorded"</name>
  <files>scripts/repeat-named-test.sh, .planning/phases/52.2-foreground-runner/52.2-FLAKE-EVIDENCE.md</files>
  <read_first>
    - scripts/check.sh (POSIX style, error reporting)
  </read_first>
  <action>
    Write scripts/repeat-named-test.sh (`set -eu`, POSIX sh). Its arguments are: a mode (`nextest` or `inprocess`), the cargo target arguments as one string, split on purpose, the test name, and a count; it refuses any other mode with a usage line. `nextest` mode runs `cargo nextest run <target> --no-tests=fail -E "test(=NAME)"`. `inprocess` mode runs the whole target unfiltered, `cargo test <target>`, as 52.1 D-08 requires for 999.221/222/232: their races need sibling tests in one process, so a single `--exact` test would never reproduce them. It writes each run's output to a file under `mktemp -d` and removes the dir on exit. A run passes only if cargo exits 0 and the output has exactly one line equal to `test NAME ... ok`, NAME being the full module path as libtest prints it. Otherwise the script prints `run I: named test NAME matched M times` or `run I: cargo exited E`. Each mode runs count times, prints `passed K of N`, and exits 1 on any failure. Set its exec bit with `git add` then `git update-index --chmod=+x`. Run it for each carried flake test under the runner that failed. That is `inprocess` for 999.221, 999.222 and 999.232; take the module-qualified names and their targets from the 52.1 SUMMARYs, for example `-p devflow --bin devflow` for the 999.221 test and `-p devflow-core --lib` for opencode's health_fails_closed_on_a_hung_probe. Confirm each full path with `--list` output first. Record per test: the reproduction result from its 52.1 SUMMARY, N, K, and that N passes bound nothing about a rate.
  </action>
  <verify>
    <automated>scripts/repeat-named-test.sh nextest '-p devflow --test runner_e2e' a_stop_whose_sigterm_reaches_the_agent_first_records_stopped 3 && scripts/repeat-named-test.sh inprocess '-p devflow --test runner_e2e' a_stop_whose_sigterm_reaches_the_agent_first_records_stopped 1 && bash -c 'out=$(scripts/repeat-named-test.sh inprocess "-p devflow --test runner_e2e" no_such_test_name 1 2>&1) && exit 1; printf "%s\n" "$out" | grep -F "named test no_such_test_name matched 0 times"'</automated>
    <fails_when>either positive run exits non-zero ("passed K of N" with K below N, or nextest's "error: no tests to run"), or the inprocess run with a name that does not exist exits 0 or does not print "named test no_such_test_name matched 0 times"</fails_when>
  </verify>

    - The evidence file has one row per carried flake with its mode, target, full test path, N and K, and a row closing 999.223 with the removal commit. 999.221, 999.222 and 999.232 rows are `inprocess`.
  </acceptance_criteria>
