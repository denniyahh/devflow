<objective>
Tell the operator which route an answer runs before it runs, and make every gate's way on come from the routers that
run it (D-10, D-37, D-39, GATE-04). 52-29 built `can_finish`, `next_step`, `answer_family`, `approve_route`,

`gate approve` print, and the sentence that leads every gate's context.

and GATE-04's "way on" sentence, from one source, so a print or a gate text can never name a route the supervisor does
not run. Split out of 52-29 by the 2026-11-10 checker revision (scope), unchanged in substance from 52-29's old Task 4.
Output: the CLI refusal and route print for both answers, the way-on helper called by every gate writer, the removal
of the hand-written answer texts, and the OPERATIONS.md text.
</objective>
