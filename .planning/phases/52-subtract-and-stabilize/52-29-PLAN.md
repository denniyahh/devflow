<objective>
Give a rejected Validate its small fix route — `/gsd-quick` with the operator's note — and make sure a quick fix outside
the report's covered files still gets re-verified (D-10, D-33). Answer every verification gate by D-37's one rule:
approve follows the GSD status the gate recorded, reject runs `/gsd-quick` with the note, abort ends the run (52-31 adds
the rate-limit gate's arms); and tell the operator which route an answer runs before it runs.

Purpose: GATE-02's second half; check 5 showed a fix that only adds an uncovered file never goes stale in GSD. D-37
replaces the per-kind routes (and the operator checkpoint this plan used to carry) with a rule over the status, so the
routes are total without asking per kind.
Output: quick-fix route, uncovered-change check, `GateFile.gsd_status`, `answer_basis`, `reject_route` and
`approve_route`, the route print for both answers.
</objective>
