<objective>
Close 999.76 (ROADMAP criterion 6): Layer 0 external verification computes a worktree-aware
`execution_root` and then discovers the PLAN's declared commands from `project_root` on the very
next line, using `execution_root` only later to run probes. `.planning/` is tracked content, so an
in-flight phase's `{N}-PLAN.md` lives on `feature/phase-{N}` **inside** the worktree and is absent
from the main checkout for the phase's whole duration — the declared probe set silently never runs.
The same root defect at `verify::phase_has_blocking_human_checkpoint` silently kills the plan-28-03
checkpoint auto-decide path in worktree mode, and is fixed in the same change.

Purpose: DevFlow's default operating shape is worktree mode. Everything the Validate trust boundary
is built around — Layer 0's affirmative-success arm, `decided_by_layer == Some(0)`, the classifier's
`Ambiguous` arms — is inert there today.

**This plan MUST NOT land without plan 34-01's graft fix**, and `depends_on` records that as a real
edge rather than prose. Making Layer 0 discovery work in worktree mode makes
`decided_by_layer == Some(0)` common rather than rare, which is precisely the graft's precondition:
shipping 999.76 alone widens a live hole (D-13, D-15, ROADMAP criterion 6's own closing sentence).

Output: discovery relocated to the execution root at both call sites, an inverted companion fixture
that distinguishes worktree discovery from main-checkout discovery, a `verify.rs` test for the second
call site, and a rewritten in-source record acknowledging the overturned prior decision.
</objective>
