## Planner decision record

### P-01 — Conformance suite is code, not prose

`test_contract()` is a real function returning `Vec<ContractResult>` (or failing), with one case per
contract method. It is the extension point — a future driver's "is it done" is "does it pass
test_contract()". Prose docs reference it, they do not replace it.

### P-02 — InteractivityMode is data-driven

The per-stage mode comes from the driver, not a hardcoded `match AgentKind` in `preflight.rs` OR the
start-time gate at `commands.rs:289`. The Codex-Define check becomes a generic "driver reports
`RequiresExistingArtifact` for Define" read in BOTH places.

### P-03 — AgentAdapter removal is enumerated, not grepped

Before deleting `AgentAdapter`, enumerate the KNOWN call sites (verified 2026-08-15):
`canary.rs:40` (Phase-31 nonce-canary), `test_support.rs:205/244` (test doubles), `preflight.rs:1266`
+ `pipeline_launch.rs:190` (`&dyn AgentAdapter` params). These files are in `files_modified`. If
37-03 left the shim routing all four agents to `AgentDriver`, migrate those call sites and delete the
trait. Removal is a HARD gate — if any call site remains unmigratable, record it as an explicit
follow-up (a `999.x` entry), not a silent deferral.
