<objective>
Make the Hermes cron instruction DevFlow prints actually runnable, and make the schedule it carries
name an unambiguous instant instead of five bare cron fields whose meaning depends on how the
operator's scheduler happens to be configured.

Purpose: #148. The printed instruction names a flag the installed Hermes CLI does not have, and the
schedule is emitted as UTC-valued `M H D M W` fields that Hermes evaluates against its own
configured timezone — so a resume scheduled for 20:46 UTC fires four hours late on a
America/New_York scheduler.

Output: an ISO-8601 instant schedule, a runnable operator hint, and tests on both sides.
</objective>
