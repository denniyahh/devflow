**Resolved: what "leaves `develop` untouched" means on the mismatch path (D-09).**
The proven script runs the merge, then compares trees, then refuses — so a
mismatch leaves the *local* merge commit in place for the operator to inspect,
and leaves the *remote* `develop` untouched because nothing is pushed. This plan
ports that behavior exactly, and D-09 itself says "matching the proven script's
behavior." Undoing the local commit would require a hard reset, which is an
automatic compensating action D-05 forbids. B4's test therefore asserts the
**remote** ref is byte-identical before and after, not that the local branch is.
Do not "fix" this later into a reset.
