## Implementation Decisions

### Scope
- **D-01 (auto):** The plans cover the nine OPEN rows (with 999.253 folded into 999.240) and the three FIXED-unconfirmed
  rows. The four FIXED rows (999.189, 999.193, 999.202, 999.219) are closed in ROADMAP.md with the evidence above and get no plan.
- **D-02 (auto):** Each FIXED-unconfirmed row (999.206, 999.213, 999.251) gets a named regression test of the behaviour
  its entry describes. If the test fails on the current code, the fix joins the same plan. If it passes, the entry is
  closed with the test's name. 999.251 is tested through the runner: resume after an `--until plan` halt launches Code, not Plan.
- **D-03 (auto):** 999.252 is a GSD defect, so no DevFlow code changes for it. It is logged in the GSD incident log, and
  an upstream gsd-core issue is left to the operator (opening one is outward-facing).

### Gate text (999.249, 999.250, 999.254)
- **D-04 (auto):** The rate-limit gate prints the reset as a UTC time and a distance ("in 2 d 4 h"). When the reset is
  past a named threshold constant (proposal: 6 h), its first answer is `resume --agent <other>` (or the configured
  fallback), not approve, and approve's text says it relaunches the same agent into the same limit.
- **D-05 (auto):** A stage-failure gate whose reason asks for operator decisions says to answer it with
  `gate reject --note "<decisions>"`, and that the note reaches the fix pass (999.189 is fixed). No new gate kind.
- **D-06 (auto):** For 999.254, the change is text, not a new route. The Phase 53 close-out route worked: reject with a
  note naming the sign-offs already done, so `/gsd-quick` records them and Validate re-runs. The `human_needed` Validate
  gate names that route. OPERATIONS.md documents it and the separate-install-root way to run live proofs while a run is
  parked. Re-judging GSD's verification in DevFlow stays out, per the Phase 52 single-check reset (D-45/D-46).
  — **Reversibility:** reversible

### Hooks and scripts (999.240, 999.255)
- **D-07 (auto):** The stale-state marker moves out of the tracked `.planning/user/errors/state-stale.json` into an
  untracked path. The hook's header already says it lives under `.devflow/`. A post-commit hook then never dirties a
  phase tree, and an installed build no longer reads `dirty`. The tracked file is `git rm`'d in the same change, and
  `.planning/user/DEV-SETUP-CHECKLIST.md` is updated, as the repo requires for hook changes.
- **D-08 (auto):** `scratch-dogfood-repo.sh --live-payload` writes a minimal `01-CONTEXT.md`, and `--selftest` asserts
  it exists, so a codex proof run starts on the fixture unchanged.

### Classification and finish (999.201, 999.259)
- **D-09 (auto):** The stream path classifies a `result` with `subtype: error_rate_limit` as RateLimited, the same as
  the single-document path. There is a proptest or table test over both paths, with a non-rate-limit `error_*` subtype
  as the negative control.
- **D-10 (auto):** When a run finishes, the finish route calls GSD's own `phase.complete` through `gsd-tools`
  (`gsd_run query phase.complete N`), so STATE.md and ROADMAP.md read the phase complete. A refusal (e.g. stale
  verification) is printed, recorded as an event naming GSD's text, and does not undo the finish. DevFlow does not edit
  STATE.md or ROADMAP.md itself. Re-verifying after a post-Validate PR fix stays a documented operator step: GSD names
  `/gsd-execute-phase N`, which is recorded as a hand-run stage. — **Reversibility:** reversible

### Tests and the PR #245 leftovers (999.257, 999.258)
- **D-11 (auto):** The notify marker hook writes to a temp file and renames it into place, so the test can never read a
  half-written marker.
- **D-12 (auto):** 999.258 is three small fixes: warn on an unparsable question gate id, record a cancel only for a
  queued or in-flight id, and correct the pi doc comment.
- **D-13 (auto):** Every fix has one named test that fails on the old code with its intended assertion text, checked
  once by reverting the fix (the negative control). Gates follow the repo traps: `cargo nextest run --no-tests=fail -E
  'test(=…)'`.

### Review tier
- **D-14 (auto, orchestrator's classification):** Tier B. The phase changes gate text, a hook, a test script and two
  routes. Nothing in it is irreversible or on the release path, and no public `devflow-core` item is removed (run
  semver-checks if one changes). One external review round on the plan set (codex and agy, adversarial lens), then execute.

### Claude's Discretion
