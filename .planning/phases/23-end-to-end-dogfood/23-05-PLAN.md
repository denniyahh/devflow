**`supervisor_socket_dir() -> Result<PathBuf, MonitorError>`** — resolve
`$XDG_CACHE_HOME`, falling back to `$HOME/.cache`; join `devflow`. Create it if
absent and set its mode to **0700**. Deliberately **not** `$XDG_RUNTIME_DIR`:
systemd removes `/run/user/$UID` when the user's last session ends, which would

security control, not tidiness: it closes the window between `UnixListener::bind`
and the socket file's own `chmod`, during which the socket is briefly
world-connectable.

**`supervisor_socket_path(project_root: &Path, phase: u32) -> Result<PathBuf, MonitorError>`**
— `<dir>/<hash>-<phase>.sock`, where `<hash>` is 12 lowercase hex characters of
a **64-bit FNV-1a** hash of the project root's byte representation, implemented
inline (a dozen lines: offset basis `0xcbf29ce484222325`, prime
`0x100000001b3`). Do **not** use `std::collections::hash_map::DefaultHasher` —
its output is explicitly not guaranteed stable across Rust releases, and a
toolchain upgrade mid-run would change the derived path. The hash keys concurrent
projects apart; the phase suffix keys concurrent phases apart. Return
`SocketPathTooLong` if the resulting path is **104 bytes or longer** — the
macOS `sun_path` bound, applied on every platform so a path that works here
cannot silently be one that fails there.

**`request_shutdown(socket_path: &Path, reply_timeout: Duration) -> Result<ShutdownOutcome, MonitorError>`**
— connect, write the line `shutdown`, read one line of reply, return
`ShutdownOutcome::Stopped`. If the socket is `Gone` or `Stale`, return
`ShutdownOutcome::NotRunning` rather than an error — a stop against an
already-dead phase is a normal, idempotent outcome, not a failure. Declare
`ShutdownOutcome` as a public enum with those two variants.

**`sweep(dir: &Path) -> Vec<(PathBuf, SocketState)>`** — list the directory,
keep entries whose extension is `sock`, probe each with `socket_state`, return
the pairs sorted by path. This is R-J: it answers "what supervisors exist on
this machine" with no state file at all, which is what makes F7 (no state ⇒ no
teardown) solvable. It must not error on an unreadable directory — return an
empty vector, since "no cache dir yet" and "no supervisors" are the same
answer to the caller.

**`boot_id() -> Option<String>`** — read and trim
`/proc/sys/kernel/random/boot_id`. `None` if unreadable.

**`process_start_time(pid: u32) -> Option<u64>`** — read `/proc/<pid>/stat` and
return field **22** (`starttime`, in clock ticks since boot). Parse defensively:
the second field is the comm name in parentheses and may itself contain spaces
and parentheses, so split on the **last** `)` before splitting the remainder on
whitespace. `None` on any parse failure or on a non-Linux target.

**`reap_stale_group(handle: &SupervisorHandle, grace: Duration) -> Result<usize, MonitorError>`**
— the STALE-path backstop, and the only code in this phase that signals a
process group. It must **fail closed**:
1. Refuse unless `socket_state(&handle.socket_path)` is exactly `Stale`. A
   live supervisor owns its own teardown; a `Gone` socket has nothing to reap.
2. Refuse if `boot_id()` returns `None` or differs from `handle.boot_id` —
   after a reboot the recorded pgid means nothing. Return
   `HandleIdentityMismatch`.
3. Refuse if `process_start_time(handle.agent_pgid as u32)` returns `None` or
   differs from `handle.agent_start_time`. This is the F3 (PID reuse) guard and
   the RESEARCH security register's spoofing mitigation. Do **not** skip it as
   an optimisation, and do **not** downgrade a `None` to "assume it matches" —
   on a platform where start time is unavailable, the correct behaviour is to
   refuse to signal, not to signal blind.
4. Only then: `libc::killpg(pgid, SIGTERM)`, poll for the group to empty for
   `grace`, escalate to `SIGKILL`, and remove the stale socket file. Return the
   number of group members observed before the first signal.
