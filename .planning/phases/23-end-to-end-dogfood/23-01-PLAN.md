<objective>
Remove the two things that would make 23a's probe meaningless before it runs: a
stale binary, and the absence of a valid probe target.

RESEARCH.md § Runtime State Inventory measured the installed `devflow` on PATH
at **v1.8.0, built 2026-07-23**, while `Cargo.toml`'s `[workspace.package].version`
already reads **1.8.1**. CONTEXT.md requires 23a to run against a **≥v1.8.1**
binary. Validating a dogfood fix against a stale binary is a documented,
recurring failure on this project — it gets its own task and its own acceptance
criterion here rather than being a bullet inside the probe task.

The second half is Claude's-Discretion item #2 from CONTEXT.md: **what minimum
`.planning/` + git structure a scratch repo needs to be a valid `devflow start`
target.** That call is made and recorded here, as a script, not as prose.

Purpose: make the 23a probe's finding trustworthy. A probe that dies because
the binary was old, or because the target repo was not a legal devflow target,
tells us nothing about the supervisor.
Output: a rebuilt binary on PATH, a committed scaffold script, and a setup
record documenting the scaffolding decision.
</objective>

single-task phase in a fresh repo**, not an imported real backlog item: the
probe is about the supervisor/pipeline mechanism, not about the content of the
work, and importing real work into a throwaway repo adds risk for no signal.

`.planning/{PROJECT.md,ROADMAP.md,STATE.md}`; one phase directory carrying a
trivial, already-written plan so Define/Plan have a real target; and whatever
agent-runtime config (`.claude/`) `devflow`'s own preflight requires.
Acceptance is behavioural, not structural: `devflow doctor` returns no blocking
finding and `devflow start --phase 1 --dry-run` prints the full pipeline.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| scaffold script → operator's filesystem | The script creates directories and git repos at an operator-supplied path; a bad path could write into the live checkout |
| scaffold script → operator's global git config | `git config` without `--local` would mutate the operator's machine-wide identity |
| rebuilt binary → PATH | Whatever the script installs becomes the binary every later plan and the operator run |
