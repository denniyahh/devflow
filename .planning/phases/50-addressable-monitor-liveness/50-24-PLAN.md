## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| launcher → new supervisor | the launcher records a socket only after it answers; a failed launch must not leave an agent |
| launcher → `/proc` | the teardown chooses its targets from `/proc` entries another process could recycle |
