<objective>
Land 999.141's test isolation first, as D-07 requires: every e2e child that runs the `devflow` binary gets a tempdir
`HOME`, `XDG_CACHE_HOME`, `XDG_CONFIG_HOME` and `DEVFLOW_CACHE_DIR`, has the repo-local `GIT_*` variables removed, and
owns and reaps any monitor it launches. The sweep and every socket test in later plans read the cache directory, so
they are unsafe until this lands.

This plan creates the shared helper, proves it with the R-13 negative-controlled test, and migrates the two suites
that launch real runs most (`start_lock_e2e.rs`, `stop_e2e.rs`). 50-03 and 50-21 migrate the remaining files and 50-04 migrates
`recover_clean_e2e.rs`.

Purpose: no later Phase 50 test can bind a socket or register a root in the operator's real cache.
Output: `tests/common/mod.rs`, `tests/test_home_isolation.rs`, two migrated suites.
</objective>
