## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Rust built-in test harness (rustc 1.97.1), `tempfile`, `insta`; TDD mode on |
| **Config file** | `scripts/check.sh`, `rust-toolchain.toml`, workspace `Cargo.toml` |
| **Quick run command** | `cargo nextest run -p devflow-core --lib --no-tests=fail` then `cargo nextest run -p devflow --bin devflow --no-tests=fail` (whole targets: a module filter is a substring filter) |
| **Full suite command** | `scripts/check.sh all` (then `scripts/check-in-container.sh` before push) |
| **Estimated runtime** | quick: tens of seconds; full: several minutes (container 2–9 min cold) |

**Exact-name rule:** run each named test as its own command, chained with `&&`:
`cargo nextest run -p <pkg> <--lib | --bin devflow | --test T> --no-tests=fail -E 'test(=<exact name>)'`.
Verified 2026-10-16 on cargo-nextest 0.9.148: with `--no-tests=fail` a name that matches nothing exits 4 ("0 tests
run"); without that flag, or under `cargo test` (which is why no row here uses it), a wrong name exits 0. Put one name
in each filter: `-E 'test(=real) | test(=wrong)'` runs the one real test, skips the wrong name silently and exits 0.
Names: lib and bin unit tests take the full module path (`lock::tests::holder_status`; with `--bin devflow`,
`commands::tests::a_corrupt_state_file_warns_while_an_absent_one_is_silent`, whose bare fn name exits 4); integration
tests (`--test T`) take the bare fn name (`T::fn` exits 4); `doc_check`'s tests have no `tests::` segment
(`doc_check::source_devflow_env_vars_and_subcommands_are_documented`). A suite run is the whole target with
`--no-tests=fail`, and its exit code is the verdict. A structural check ("no X left", "every Y documented") is a Rust
source-scan test run by name, not a shell count, because `rg -c` prints nothing rather than `0` on zero matches. The
package is `devflow`, not `devflow-cli`, and it is binary-only: use `--bin devflow`, never `--lib`.

## Sampling Rate

- **After every task commit:** the task's named tests (one command per name, per the exact-name rule) plus `cargo nextest run -p devflow-core --lib --no-tests=fail` or `cargo nextest run -p devflow --bin devflow --no-tests=fail` for the touched crate
- **After every plan wave:** `scripts/check.sh all`; `cargo clippy --workspace --all-targets -- -D warnings`; the macOS compile gate (V-54's command; needs `rustup target add aarch64-apple-darwin`); each plan's own mutants gate, re-run as written in it (50-05 on `probe` in `supervisor.rs`, 50-07 on the decision fns in `supervisor/runtime.rs`, 50-09 on `classify` in `supervisor/backstop.rs`; each a `cargo mutants -v --no-shuffle -f <file> -F <fns>` run scoped to its module's tests, with no surviving mutant)
- **Before `/gsd-verify-work`:** full suite green, `scripts/check-in-container.sh`, the V-27 semver comparison, then the live rig
- **Max feedback latency:** the quick command; the full suite runs at wave boundaries
