RESEARCH probes (this host, with negative controls): `connect()` gives ECONNREFUSED for a regular file and a
directory (so `lstat` + `S_ISSOCK` + uid must come first); `rename` replaces a live socket while `hard_link` returns
EEXIST; a connect between `bind` and `listen` is refused; std's `UnixListener::bind` binds 107 bytes and refuses 108
with an errno-less `InvalidInput`, so DevFlow needs its own named check. `devflow-core` is published: every new `pub`
item is listed under "Artifacts", and new public error enums are `#[non_exhaustive]` from the start (R-9). Tests build
socket dirs with `tempfile::Builder::new().prefix("dfs").tempdir_in("/tmp")` so paths stay far below 107 bytes even if
`$TMPDIR` is long. Single-test gates use `tools/exact-test.sh` (50-01).

Wire protocol (Claude remit, RESEARCH Finding 8; D-20 means no version field): one request per connection, one JSON
object per line, 4 KiB cap, 2 s read/write timeouts, server rejects a peer whose `SO_PEERCRED` uid differs from its
euid. Requests `{"op":"ping"}` and `{"op":"shutdown"}`. Ping reply
`{"ok":true,"launch_id":…,"phase":…,"stage":…,"launch":"capture"|"stream","owner":"agent_running"|"advancing"|"gate_wait"|"handed_off","agent_pid":N,"agent_pgid":N,"agent_start_time":T,"boot_id":…,"supervisor_pid":N}`;
shutdown replies `{"ok":true,"accepted":true,"owner":…}` then `{"ok":true,"stopped":true,"exit_code":143,"advance_suppressed":true}`,
or `{"ok":false,"error":"handed_off"}`; anything else `{"ok":false,"error":"unknown_op"}`. The pids in a reply are for
display only; nothing on the liveness path reads them. The launch labels are `capture` (the `MonitorLaunch::Legacy`
shape: stdin null, stdout to a file) and `stream` (the `MonitorLaunch::PipeOwning` shape).
