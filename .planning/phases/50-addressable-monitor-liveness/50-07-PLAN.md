RESEARCH Finding 3 (verified on this host): a blocked mask is inherited by children spawned with `Command`, while
caught handlers reset on exec — so use `sigaction` + self-pipe, never `sigwait`. Handler: `if getpid() ==
SUPERVISOR_PID { write(fd, &signo, 1) }`, pipe made with `pipe2(O_CLOEXEC | O_NONBLOCK)`, `SA_RESTART`. The pid guard
drops a write from a forked child that has not exec'd yet. Waiting: `waitid(P_PID, pid, WEXITED | WNOWAIT)` observes the
exit without reaping, so a zombie leader still holds the pgid while leftover members are SIGKILLed; only then reap.
Escalation constants: reuse `agent::TERMINATE_VERIFY_WAIT` / `TERMINATE_VERIFY_POLL` (their doc asks callers not to
invent new ones). Group-signal guards: `pid_t::try_from`, `> 1`, and never `getpgrp()` (the `monitor::terminate_child_group`
shape). Process-global signal state is installed only in a supervisor process, so tests run the supervisor half in a
child test process via `devflow_core::test_support::spawn_test_in_child` (50-05) and never install a handler in the
test harness process.

Owner semantics (RESEARCH Finding 3, R-2): AgentRunning + stop → kill the group, outcome Stopped; Advancing + stop →
flag only, the CLI's next safe point stops; GateWait + stop → flag, the cancellable gate poll returns Abort (50-13);
HandedOff + stop → reply `handed_off`, act on nothing; Finished + stop → reply that the run already finished.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| signal delivery → supervisor | asynchronous; work in a handler is unsafe |
| supervisor → agent process group | a group kill must target only the agent's own group |
| socket client → shutdown | a request decides whether a run is killed |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-50-16 | Denial of Service | signal handling | high | mitigate | Self-pipe handler with only getpid+write; no blocked mask (agents would become immune to the group TERM); test asserts the agent's SigBlk/SigCgt |
| T-50-17 | Tampering | stop/completion race advancing a stopped run | high | mitigate | All decisions under one owner mutex; V-14 enumerates interleavings with a control; mutants on the decision fns |
| T-50-18 | Elevation of Privilege | group kill hitting pgid 0/1 or the supervisor's own group | high | mitigate | One guard fn (`pid_t` fit, > 1, ≠ getpgrp); group kills only while the leader is unreaped |
| T-50-SC | Tampering | npm/pip/cargo installs | low | accept | No package installed; libc only |
</threat_model>
