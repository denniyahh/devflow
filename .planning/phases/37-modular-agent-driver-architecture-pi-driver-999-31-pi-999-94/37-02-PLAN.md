## Planner decision record

### P-01 — Trait lands whole, drivers land one at a time

Define the full `AgentDriver` trait in one place (so the interface is stable before three more
drivers implement it), but migrate Claude and OpenCode to it incrementally in this plan. A partial
trait landed twice is worse than a complete trait landed once.

### P-02 — Compatibility shim, not big-bang

`adapter_for` keeps returning the old `AgentAdapter` box for Codex/Pi (still on the old trait in
37-03) and wraps Claude/OpenCode drivers behind it, so `pipeline_launch.rs` and every caller keep
compiling. The shim is the D-11 conditional-removal point — deleted in 37-04 only after all four
agents are on `AgentDriver`.

### P-03 — Claude zero-regression is proven, not asserted

The ClaudeDriver's `build_command` output is snapshotted against the current `exec_command` argv,
and its `render_prompt` against the 37-01 snapshot. The `MonitorLaunch::PipeOwning` routing is
asserted to be unchanged (Claude still reaches the pipe-owning arm, never `Legacy`).
