<objective>
Give the pipe-owning monitor a failure path: when a Claude child goes quiet for longer than the
measured floor, DevFlow writes an authoritative, first-class, loudly-failing verdict to disk and
*then* terminates the child — instead of hanging forever, or falling through to a layer that
scores partial commits as Success.

Purpose: constraint 5 exists because a graceful close falls through to Layer 2, which scores
partial commits as Success — that is 999.64 reborn inside its own fix — and a bare kill
mis-classifies as OOM. Only a distinct status, written before the kill, makes "we gave up
waiting" legible to the completion oracle rather than to prose alone.

Output: `AgentStatus::IdleTimeout` wired through every exhaustive match, a side-channel verdict
file that a stale stream `result` event cannot shadow, and an idle timer that resets on every
line with a clamped-configurable floor.
</objective>

Replace the supervisor loop's `RecvTimeoutError::Timeout` arm with the real firing sequence, in
this order and no other:

     the firing sequence, because a missing commit list must not cost the operator the verdict.

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-31-06 | Repudiation | `evaluate_layer1` ordering | high | mitigate | The idle-timeout verdict is read as the first statement of `evaluate_layer1`, before `read_capture` and before `parse_claude_event_result`.
