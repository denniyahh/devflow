<objective>
SURV-01 writer rule, `start` and `stop` halves (D-01, D-02.1, D-02.3, R-5, F-1, F-5), plus SURV-02's fresh-start
leftover cleanup (D-05.4, R-1). After this plan every production state writer holds the per-phase lock, so a live
lock holder identifies a live gate waiter (the D-02 side effect 48-13 relies on).

Open Question 2 decision: the post-signal retry window is `agent::TERMINATE_VERIFY_WAIT` (3 s), applied only after a
successful signal. Rationale: DevFlow installs no signal handler, so SIGTERM ends `advance` without unwinding and its
parent shell reaps it promptly; the constant is the existing bound for "a signalled process is gone"; a longer window
only delays the message when the holder survives.

Waiter signal before 48-13: this plan cannot call 48-13's `lock::holder_status`. After `stop`'s gate path answers, lock
contention is the only waiter signal available, and it is sufficient here because every gate waiter holds the
per-phase lock once `start` takes it.

block in `start` byte-identical to c0fb193 rather than claiming the control test pins it), C-2 and C-3 (no pinning
test existed; Task 2 adds one each), C-4 (`stop_e2e.rs` gate-path test), C-5
(`stop_marks_state_stopped_and_records_reason`), C-27 VALID-02 root parsing tests.
