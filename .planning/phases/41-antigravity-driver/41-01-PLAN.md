<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI argv → process spawn | Operator provides `--agent antigravity`, driver constructs argv and spawns subprocess |
| Child stdin (prompt injection) | Monitor injects user turn as JSON on child stdin; child parses and processes |
| Child stdout → event parsing | Driver reads JSON events from child stdout, parses for `DEVFLOW_RESULT` marker |
| Process exit code | Child process exit code is fallback completion signal when stream lacks `DEVFLOW_RESULT` |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-41-01 | Tampering | DEVFLOW_RESULT marker in stream | medium | mitigate | JSON structure validation in parser; reject malformed events; honest exit code fallback (D-03) |
| T-41-02 | Tampering | Untrusted agent stdout parsed as completion | high | mitigate | Parser validates `DEVFLOW_RESULT: {\"verdict\": ...}` JSON structure; missing marker → stage not advanced (marker-less regression test, ANTG-03) |
| T-41-03 | Tampering | Supply-chain risk on spawned binary (`agy` v1.1.15) | medium | mitigate | D-01 decision locks wrapper to operator-vetted version; presence-only health check; marker-less contract is functional backstop (wrong/stale binary fails honestly with no advancement) |
| T-41-SC | Tampering | Package legitimacy (new Rust dependencies) | N/A | accept | No new crate dependencies — all integrations are argv/process-level (STACK.md, CONTEXT.md D-02) |

**Disposition rationale:**
- **T-41-01, T-41-02:** Medium/high mitigated by the marker-less regression test (ANTG-03) — a run with no `DEVFLOW_RESULT` never advances the stage, forcing operator intervention or explicit debugging before the run is considered successful.
- **T-41-03:** Mitigated by D-01 operator decision (wrapper at v1.1.15) and D-03 process-exit fallback — a stale or wrong binary produces honest failure, not silent degradation.
- **T-41-SC:** N/A — no new dependencies.

**Related ASVS controls:** V4 (Access Control — skip-permissions embedded in wrapper, not driver responsibility), V5 (Input Validation — JSON structure validation + marker contract).

</threat_model>
